# 🌿 Portfólio Zen – Andriel José

Este é meu portfólio pessoal desenvolvido com foco em simplicidade, elegância e leveza visual. Criado do zero com HTML, CSS puro e JavaScript, esse projeto reflete minha jornada como desenvolvedor e entusiasta em tecnologia.

---

## ✨ Funcionalidades

- 🎨 Interface minimalista com animações suaves e tema claro/escuro
- 💬 Formulário de contato funcional com envio real via [FormSubmit](https://formsubmit.co)
- 📂 Sessão de portfólio com projetos reais hospedados
- 🧘 Estilo visual "zen", limpo e agradável

---

## 📁 Estrutura do projeto

```
/
├── index.html           # Página inicial com apresentação pessoal
├── educacao.html        # Linha do tempo com formação acadêmica
├── portfolio.html       # Lista interativa dos meus projetos
├── contato.html         # Formulário funcional de contato
├── obrigado.html        # Tela de agradecimento após envio do formulário
├── style.css            # Todo o design visual com tema escuro/claro
├── script.js            # Tema dinâmico + feedback de envio
└── assets/              # (opcional) imagens e ícones
```

---

## 🛠️ Tecnologias utilizadas

- HTML5 semântico
- CSS3 puro (sem frameworks)
- JavaScript vanilla
- [FormSubmit](https://formsubmit.co) para envio de mensagens via email
- Font Awesome para ícones

---

## 📬 Contato funcional com FormSubmit

O formulário de contato envia emails reais para meu endereço:

```html
<form
  action="https://formsubmit.co/andrielscript@gmail.com"
  method="POST"
></form>
```
